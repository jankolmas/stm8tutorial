# 02: Blink using a timer

This chapter teaches how to blink the on-board LED on the STM8 development board at a given frequency, using the internal TIMER1. 


## Build and flash

See instructions in chapter 00 on how to set up the hardware and development environment. Build the program with `make` and flash with `make flash` commands. 

You should see the onboard LED start blinking at the frequency defined in main.c
